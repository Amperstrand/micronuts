## Board session checklist (when the board is reachable)

1. **Toolchain**: the `firmware` crate does NOT currently build on this
   bench — `stm32-metapac` 21.0.0 fails (rustc exit 101) under both
   `nightly` (2026-04-03) and the repo pin `nightly-2025-12-08`, with
   `cap-lints allow`. First board-session task: bisect toolchain (try
   the embassy-recommended nightly for embassy-stm32's version) or bump
   embassy-stm32/metapac. Note: working tree has an uncommitted
   `rust-toolchain.toml` change (`nightly-2025-12-08` → `nightly`) and
   `Cargo.lock` diff — reconcile before debugging builds.
2. **Board access**: 192.168.13.208 pings (30–165 ms RTT — laggy for
   LAN; likely WiFi power-save or a mesh hop) but port 22 accepts TCP
   and never sends an SSH banner; no HTTP on 80/443/2051/2121/5000/8080.
   Confirm what the board actually runs (and which port) before the
   session; if it's meant to be the tollgate backend API on 2121, it is
   currently not serving.
3. **Firmware wiring** (after build is fixed): add `gate_app` module to
   the firmware crate implementing `GateIo` over GPIO/LED (+ optional
   display), feed GM65 scan results (via the existing `qr` module's
   `decode_qr`) to `GateController::handle_scan`. The controller owns
   everything else; the board layer should stay under ~150 lines.
4. **Provisioning**: encode accepted mint URL + pinned keysets (v2 ID +
   per-denomination keys) as build-time constants first run; flash-store
   config can come later. Sanity-check the pin with
   `nut02::verify_keyset_id` at boot (catches wrong/rotated pins).
5. **Acceptance sequence**: host-run `gate_demo` → flash → scan a valid
   CDK-minted token (generated by the `cdk_interop` test fixtures) →
   expect OPEN; rescan → ERR:Replay; scan tampered → ERR:InvalidProof;
   power-cycle → rescan → still ERR:Replay (ring persists).

## Known scope limits (by design, documented in the design doc)

- V3 (`cashuA`) tokens rejected — V4-CBOR core.
- NUT-10/11 locked secrets rejected outright.
- Offline replay window bounded by the ring capacity (4096) + no
  cross-gate sync; online NUT-07 reconciliation closes it later.
