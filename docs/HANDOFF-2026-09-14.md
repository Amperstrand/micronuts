## Hard-won operational knowledge (keep quoted)

### M5Stick flash procedure
```bash
sudo systemctl stop bolty-console
cd micronuts-esp32-wallet
source ~/esp/esp-idf/export.sh
MICRONUTS_WIFI_SSID=2 MICRONUTS_WIFI_PASS=apekattensatilgutten cargo +esp build --release
P=/home/ubuntu/.cargo-target/xtensa-esp32-espidf/release
esptool.py --chip esp32 elf2image --flash_size 4MB --flash_mode dio --flash_freq 40m \
    $P/micronuts-esp32-wallet -o $P/app.bin
esptool.py --chip esp32 -b 115200 \
    --port /dev/serial/by-id/usb-Hades2001_M5stack_49D6163EBE-if00-port0 \
    --before default_reset --after no_reset write_flash 0x20000 $P/app.bin
# Boot pulse: dtr=False, rts True→False (pyserial), wait for console
sudo systemctl start bolty-console
```

### STM32F469 flash (from micronuts repo)
```bash
cd firmware && cargo build --release
arm-none-eabi-objcopy -O binary target/thumbv7em-none-eabihf/release/firmware firmware.bin
st-flash --connect-under-reset write firmware.bin 0x08000000
st-flash --connect-under-reset reset
# CDC appears after ~60s splash; detect by VID:PID 16c0:27dd
```
